Key Sharing (ECDH)

ECDH lets two people create the same shared secret without sending the secret over the network. Each person keeps a private key and shares their public key. When one person's private key is combined with the other person's public key, both sides arrive at the same value.

How to use this
  1. Each person generates an ECDH key pair on the Keys page.
  2. Each person sends their public key to the other person (download the .pem file or use the copy button).
  3. On this page, select your own private key and the other person's public key.
  4. The site computes the shared secret and saves it as an AES-256 key you can use to encrypt files.

This key never leaves the site. Only the matching public key is shared.
