Anyone can view these posted carriers. The hidden message is not visible without the correct starting bit (S), spacing (L), and mode (C).

Finding the message with only L

If someone knows only L, they would still need to try every possible starting bit S and guess whether L is fixed or part of a variable pattern C. They would also have to recognize the extracted bytes as a real message. A small carrier or a simple L makes guessing easier, but changing S, using a variable L list, or starting with a large S inside the file makes the search much harder.
